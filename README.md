# Anija Jones — Professional Portfolio Website

Static, responsive portfolio website for **Anija Jones Daniel Chandra**, Senior Business Analyst &amp; Test Lead.
Built with plain HTML, CSS and JavaScript — no frameworks, no build step, no external dependencies.

All content on the site comes directly from the supplied CV. Nothing has been invented.

## Viewing locally

Double-click `index.html`, or run a local server:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Deploying

Double-click **`deploy.bat`** (or run it from a terminal):

```bat
deploy.bat
```

The script will:

1. Verify `index.html`, `css\styles.css` and `js\main.js` exist
2. Check Git is installed
3. Create a git repository **for this folder only** (all commands are scoped with `git -C`, so an enclosing repository elsewhere on the machine cannot capture these files)
4. Set `user.name` / `user.email` only if no identity is configured yet
5. Normalise the branch to `main`
6. Point `origin` at `https://github.com/Programmer7-dev/AnijaJones.git`
7. Write `.gitignore`, stage and commit
8. Push to `origin/main`, retrying once with a rebase if the remote has newer commits
9. If the GitHub CLI (`gh`) is installed and signed in, attempt to switch GitHub Pages on

### Before the first run

Create the repository once at <https://github.com/new> — name it `AnijaJones`, leave it **empty** (no README, no .gitignore). If it already exists, the script just uses it.

If Git asks you to sign in when pushing, run this once:

```bat
git credential-manager github login
```

## GitHub Pages

The script attempts automatic setup. Otherwise enable it manually:
**Settings → Pages → Deploy from a branch → `main` / `(root)`**.

Once published, the site is live at:

```
https://programmer7-dev.github.io/AnijaJones/
```

## Notes

- **Fonts** — Inter and Source Serif 4 load from Google Fonts. Offline, the site falls back to Segoe UI / Georgia and still looks correct.
- **Social preview image** — `assets/og-image.svg` is an SVG. Most social platforms only render PNG/JPEG previews, so export it to PNG and update the `og:image` path in `index.html` if link previews matter to you.
- **Printing** — the "Print / Save as PDF" button uses a dedicated print stylesheet that flattens the layout to white-on-white, drops navigation and buttons, and prevents page breaks inside entries.
- **Editing content** — every line of copy lives in `index.html`. Edit the text there; no component system to learn.
- **Accessibility** — skip link, keyboard-navigable menu, `aria-expanded` on the mobile toggle, visible focus rings, and `prefers-reduced-motion` support are all built in.
